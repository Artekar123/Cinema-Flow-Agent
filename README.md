# Cinema-Flow-Agent
El proyecto Cinema Flow Agent pretende hacer del cine un entretenimiento, las personas llegan al cine con su entrada adquirida, pero antes de entrar deben hacer una fila para comprar snack .Pueden perder parte de los trailers y creando agentes de IA se  permita que el espectador compre su combo antes de llegar al cine, lo retire rápidamente,
